# NextDrive | Luxury Car Platform 🏎️✨

**NextDrive** es una plataforma web frontend de alta gama especializada en la exhibición, comparación y gestión de vehículos de lujo y superdeportivos. Diseñada con una estética minimalista **"Black & Gold"**, ofrece una experiencia de usuario fluida, inmersiva y sofisticada.

---

## ✨ Características Principales

* **Catálogo Exclusivo:** Visualización de superdeportivos, SUVs y sedanes de lujo con filtros avanzados por categoría y búsqueda en tiempo real, blindado contra errores de datos.
* **Simulador de Financiación:** Herramienta interactiva para calcular cuotas, plazos y pagos iniciales personalizados.
* **Comparador de Vehículos:** Módulo de comparación lado a lado para evaluar especificaciones técnicas, rendimiento y precios.
* **Gestión de Citas y Favoritos:** Sistema completo para agendar visitas a showrooms y guardar vehículos predilectos con persistencia local (`localStorage`).
* **Panel de Administración:** Interfaz dedicada para la gestión y control del inventario de vehículos.
* **Diseño UI/UX de Lujo:** Estética oscura optimizada con efectos de vidrio esmerilado (*Glassmorphism*), transiciones de zoom suave en tarjetas, barra de desplazamiento personalizada y notificaciones *Toast* elegantes.

---

## 🛠️ Tecnologías Utilizadas

* **React** (con Vite para un entorno de desarrollo ultrarrápido)
* **Tailwind CSS** (para un diseño estilizado, responsivo y de alta gama)
* **React Router DOM** (para la navegación multipágina fluida)
* **JavaScript (ES6+)**
